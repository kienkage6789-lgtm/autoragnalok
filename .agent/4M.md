## 2. BIỆN PHÁP KHẮC PHỤC (CORRECTIVE ACTIONS)

Hệ thống đã được khắc phục hoàn toàn thông qua hai chỉnh sửa cốt lõi tại Frontend và Backend, kèm theo cập nhật bộ kiểm thử tự động.

### 2.1. Sửa lỗi phân loại giao diện (Frontend)
Tại [`public/app.js`](file:///C:/Users/Admin/Desktop/autoR/autoragnalok/public/app.js#L5103-L5105):
*   **Trước đây:** Hàm `isMvpName()` nhận diện tất cả quái bắt đầu bằng `"Vua"`, `"Chúa tể"`, `"Tướng quan"`,... là MVP. Điều này khiến `"Vua sói"` bị chuyển sang danh sách MVP (không hiển thị ở danh sách thường) và mất tiền tố `"MVP "` hiển thị (gây trùng lặp tên `"Vua sói"` ở cả hai nơi).
*   **Giải pháp:** Rút gọn hàm `isMvpName()` chỉ kiểm tra nếu tên bắt đầu bằng `"MVP "`.
    ```javascript
    function isMvpName(name) {
      return name.startsWith('MVP ');
    }
    ```
*   **Kết quả:** Quái `"Vua sói"` nằm đúng ở danh sách thường, còn bên danh sách MVP hiển thị chính xác là `"MVP Vua sói"`.

### 2.2. Sửa lỗi so khớp mua nhầm (Backend)
Tại [`server.js`](file:///C:/Users/Admin/Desktop/autoR/autoragnalok/server.js#L3475-L3557):
*   **Sửa lỗi so khớp lỏng lẻo:** Thiết lập cơ chế so khớp nghiêm ngặt (Strict Type Matching). Chỉ thực hiện so khớp tên nếu cả hai cùng là MVP hoặc cùng là quái thường (`isSelectedMvp === isItemMvp`). Nếu lệch loại, lập tức bỏ qua.
    ```javascript
    const isSelectedMvp = cardName.toLowerCase().startsWith('mvp ');
    const isItemMvp = itemLower.includes('mvp');
    if (isSelectedMvp !== isItemMvp) return false;
    ```
*   **Sửa lỗi để trống vẫn mua tất cả (Empty Whitelist Fallback):** Thay đổi logic kiểm tra mảng cấu hình lọc của tất cả 7 danh mục có bộ lọc (`card`, `egg`, `module`, `collectible`, `module_box`, `card_box`, `egg_box`). Nếu mảng cấu hình rỗng (người dùng không chọn mục nào), lập tức bỏ qua không quét mua (`continue` thay vì bỏ qua bộ lọc).
    ```javascript
    if (!Array.isArray(selectedCards) || selectedCards.length === 0) continue;
    ```
*   **Kết quả:** Dứt điểm hoàn toàn lỗi mua nhầm và mua ngoài cấu hình. Khi bật danh mục nhưng không tích chọn bất kỳ ô lọc cụ thể nào, bot sẽ không mua bất kỳ vật phẩm nào thuộc danh mục đó.
